Getting Started with Tracklab IM

First Time Login

Step 1: Access the Application

  1. Open your web browser and navigate to your Tracklab IM instance URL
  2. You should see the main dashboard after authentication
  3. Your profile information appears in the bottom-left of the sidebar
💡 Tip: Bookmark the URL for quick access. The app works on any modern browser on desktop, tablet, or phone — the header collapses to icon buttons below 768 px so it stays usable on small screens.
🔐 Single-session sign-in: Only one device can be signed in per account. If you sign in on a phone while your desktop tab is still open, the desktop tab will show a toast and drop back to the login screen within 30 seconds (immediately on refocus).

Understanding the Interface

The Sidebar Navigation

The left sidebar contains all major sections, organized into groups:

  • Core Sections: Dashboard, Items & Inventory, Stock Tables, Reports & Ledger, Pricing Directory, Suppliers, Bookkeeping, Production Costs
  • CAD & Manufacturing: P&P Kit Booking, Bill of Materials, Pick & Place, Component Alternates
  • Project Management: Project Manager
  • Automation: Automation Dashboard, Auto-PO Config
  • Quality & Analytics: Quality & Compliance, Advanced Automation
  • Administration: System Config
💡 Tip: Click section headers in the sidebar to expand/collapse categories and reduce clutter.

Essential Settings

Step 1: Configure Basic Settings

  1. Click Settings → System Config
  2. Set your preferred visual theme (Dark/Light mode)
  3. Enable/disable low stock alerts
  4. Configure sync frequency for real-time or interval-based updates

Dashboard Overview

The Dashboard is your command center, providing real-time insights into your inventory, projects, and business operations.

Key Metrics Cards

Understanding the Statistics

  • Total Items: Complete inventory count with trend percentage
  • Active Projects: Current project status (Stable/At Risk)
  • Low Stock Alerts: Items requiring immediate attention
  • Critical Shortages: Number of items urgently needed
  • Asset Valuation: Total monetary value of inventory

Stock Status Overview

Monitor Stock Levels (Donut Chart)

  • In Stock (66%): Items with adequate stock levels
  • Low Stock (8%): Items below low stock threshold - needs attention
  • Critical (26%): Items requiring urgent reordering

Total SKU count displayed in center of donut chart

Navigating faster

“Needs attention today” strip

New panel at the very top of the dashboard turns the passive stats board into an action queue. Five click-through cards, refreshed every 60 seconds:

  • Quotations awaiting reply — count + open value. Click → Sales > Orders filtered to QUOTATION.
  • Sales orders with backorders — any SO where reservations exceed on-hand.
  • Overdue invoices — count + total balance owing.
  • Bills due this week — anything AWAITING_PAYMENT / PARTIAL / OVERDUE with a due date ≤ today+7.
  • Critical low stock — parts flagged critical on the inventory grid.

Cards render even at zero so the layout doesn't shift; when every queue is empty the strip shows a "You are clear" state with a green tick.

Command palette (⌘K / Ctrl+K)

The command palette (⌘K / Ctrl+K, top of the app) already searched pages, items, clients, and suppliers. It now also finds any bookkeeping doc by its number. Type INV-, SO-, PO-, BILL-, QUO-, CN-, or DN- and every match surfaces grouped by kind, with client/supplier and status in the subtitle.

  • Fuzzy match also runs against the subtitle so "lumax invoice" or "digikey bill" filter correctly.
  • Enter jumps to the correct sub-tab (Sales > Invoices for an INV-, Purchases > Bills for a BILL-, etc).
  • Doc index is fetched once per palette-open and cached for 60 s, so repeated ⌘K is instant.

Live cross-user sync

Every 2xx write to any major entity now bumps a shared version counter on the server. Every open browser polls that counter every 25 seconds and, when anything moves, silently re-runs the initial bootstrap. So when an admin lands a CSV import, edits a client, posts a bill, or accepts a quotation, every other logged-in tab picks up the change within a single tick — no refresh needed.

Coverage: inventory · clients · client_orders · suppliers · bookkeeping (invoices / bills / POs / payments / dispatch) · projects · production_kits · BOM · pick-place.

Mobile-optimised UI

The app now detects screen size (breakpoint 768 px) and adapts the header and layout for phones.

  • The top-bar action buttons collapse to icons on small screens, freeing horizontal space.
  • A new useIsMobile hook exposes the breakpoint to any component that needs to reflow.
  • The rest of the pages are being reflowed page-by-page — check back for further mobile improvements.
