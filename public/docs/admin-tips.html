Accounts & access

One account, one active device

Signing in on a new device now automatically signs the previous device out.

  • Log in on your phone → your desktop tab shows a toast reading "Signed out — this account signed in from another device" and drops back to the login screen.
  • Detection happens on a 30-second heartbeat and immediately when you refocus the older tab.
  • Explicit logout on either device only signs that one device out.
💡 Tip: If a device seems to hang on the login screen after signing in elsewhere, that's expected — sign back in on the device you want to use.

API Keys tab

Provider credentials for every supplier can be entered and rotated from inside the app.

  • DigiKey now uses OAuth2 client_credentials where available — no more manual re-authorisation every day. Fall back to the 3-legged flow with npm run digikey:authorize if your account doesn't have it.
  • TME uses its Private Key + Application Secret; the workflow help text now matches the current TME portal.
  • The tab is protected against browser autofill hijack, so entering login credentials in your password manager will no longer redirect you to the search view.

System Optimization Tips

Performance Improvements

  • Bulk Operations: Use bulk pricing instead of updating items one-by-one; it also re-prices stale items automatically every day
  • No need to refresh: open pages pick up other people's changes by themselves within about 25 seconds (straight away when you come back to the tab). When a new version of the app is deployed, it loads by itself the next time you switch away from the tab; a Reload now banner offers it sooner.
  • Roles: every change is checked against the account's role. Admins can do everything. Managers can change and delete stock, BOMs, kits, suppliers, bookkeeping, projects, quality records and automation. Engineers can add and change stock, BOMs, kits, projects (including the Project Progress board) and quality records, run bulk pricing and fix part numbers, but not change bookkeeping, suppliers or automation, and they can't delete. Viewers can see everything and change nothing. Only admins manage users, settings and the project stages.
  • Keyboard Shortcuts: Use Ctrl+K/⌘K for global search instead of clicking
  • Filters: Apply filters before searching to reduce result set
  • Automation: Set up rules to eliminate manual, repetitive tasks
  • Caching: Pricing data cached 30 days to reduce API costs

Data Management Best Practices

Critical Guidelines

  • Unique Part Numbers: Never duplicate SKUs - verify before creating items
  • Supplier Master: Maintain accurate supplier information for correspondence
  • Regular Backups: Ensure database backups occur regularly
  • Access Control: Limit admin access to authorized personnel only
  • Audit Trail: Monitor who makes what changes for compliance

Troubleshooting Common Issues

Slow Performance

  • Clear browser cache (Ctrl+Shift+Delete)
  • Use filters to reduce large result sets
  • Check internet connection speed
  • Try different browser if issue persists

Missing or Incorrect Data

  • Refresh page (F5 or ⌘R)
  • Clear filters to ensure complete view
  • Check for pending sync operations
  • Verify user permissions for field visibility

API Connection Issues

  • Check API key configuration in system settings
  • Verify supplier API credentials are valid
  • Check network firewall rules
  • Review API rate limits and throttling
