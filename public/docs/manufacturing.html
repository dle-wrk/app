Manufacturing & Production

Bill of Materials (BOM)

Create and Manage BOMs

  1. Navigate to CAD & MANUFACTURING → Bill of Materials
  2. Click Create New BOM
  3. Enter assembly name and description
  4. Add components by:
    • Searching existing inventory
    • Specifying quantity needed per unit
    • Adding designator (reference number)
    • Including footprint and package info
  5. Review total component cost
  6. Save BOM for production use

Production Kits

Manage Production Kits

  1. Navigate to CAD & MANUFACTURING → P&P Kit Booking
  2. View available kits with status:
    • READY: Available for use
    • STAGING: Being prepared
    • BLOCKED: Temporarily unavailable
    • ACTIVE: Currently in use
  3. Book a kit for a production run
  4. Track kit status and update as production progresses

Pick & Place Operations

Manage Pick & Place Components

  1. Navigate to CAD & MANUFACTURING → Pick & Place
  2. View all P&P components organized by project
  3. Track component designators and quantities
  4. Update placement status as manufacturing progresses

Production Costs

Calculate and Track Production Costs

  1. Navigate to Production Costs
  2. View products with:
    • Model numbers
    • Production cost (BOM cost + labor)
    • Selling price
    • Margin calculation
  3. Edit costs and prices as needed

Import costs and prices in bulk

  1. Click Export CSV to download the catalogue, and edit it in Excel (or use your own sheet).
  2. Click Import and choose the file (.xlsx or .csv). Columns are found by their headers: Model # (needed) and any of Description, Category, Production cost, Selling price, Notes. In a workbook, the first sheet with a Model # column is used.
  3. Check the preview: what is new, what changes (old value crossed out, new value next to it), and anything that was left out, such as a price that isn't a number.
  4. Click Import to apply it. It all goes in at once, or not at all.
  • A model number already in the catalogue is updated; a new one is added. Nothing is deleted.
  • An empty cell keeps what is there, so a sheet with only model numbers and selling prices changes only prices.
  • Prices exclude VAT. "R 8 827,89", "8 827.89" and "8827,89" all work.
  • Admins, managers and engineers can import; everyone can export.
💡 Tip: Track BOM costs carefully - they're the foundation of accurate pricing and margin calculations.

Alternates, projects & supplier BOMs

Component Alternates

Manage Component Substitutes

  1. Navigate to CAD & MANUFACTURING → Component Alternates
  2. Define alternate components for:
    • Supply chain flexibility
    • Cost optimization
    • Lead time management
  3. Mark alternates with compatibility level
  4. Use in BOMs when primary components unavailable

Alternates — Simulation Map

In Manufacturing → Component Alternates, the "Simulation map active" chip in each group's footer is now a real button that opens a radial SVG view of the group: the highest-stock alternate at the centre, every other alternate arranged around it. Node radius scales with stock level, fill colour reports stock health (green / amber / red), and clicking a node opens that SKU in Item Detail.

Supplier BOM Generator

Manufacturing → Supplier BOM Generator. Ported from the legacy Python desktop tool. Upload a pick-and-place BOM CSV; the tool resolves each part against the three inventory supplier-PN columns (Mouser = sup_pn_1, DigiKey = sup_pn_2, LCSC = sup_pn_3) with an equivalent-reel fallback for empty columns.

  • Auto-skips DNF rows during parse. Merges duplicates by summing qty-per-PCB.
  • Per-supplier tabs with colour-coded rows: red for missing PN in that supplier, "NO PART" pill for parts unlisted at all three.
  • Bulk toggles per tab: Check all / Uncheck all / Check only rows with PN.
  • Board qty spinner multiplies through to every exported row.
  • Exports in each supplier's preferred upload shape: Mouser PN|qty, DigiKey Quantity,"Part Number", LCSC Comment,Designator,Footprint,LCSC Part #,Quantity.

Project Management

Manage Projects and Deployments

  1. Navigate to PROJECT MANAGEMENT → Project Manager
  2. Create new projects with:
    • Project name and description
    • Timeline (start/end dates)
    • Assigned team members
    • Design specifications
    • Status tracking (Planning, Active, Completed)
  3. Link BOMs and production kits to projects
  4. Track project progress on the Project Progress board

Project Progress

PROJECTS → Project Progress shows every project in the stage it has reached, so when several projects run at the same time you can see where each one is at. The stages start as Planning → Design & BOM → Sourcing → Kitting → Assembly → Testing → Complete; the last stage means finished.

  • Board or list: the board has a column per stage; the list shows the same projects as a table. The page remembers which one you used.
  • On each project: how long it has been in its stage (in amber after 30 days without a move), its due date from Project Manager (red when overdue), its BOM against stock for one build, saved kits, builds in progress, and the latest note someone wrote.
  • Moving a project: use the arrows on its card, drag the card to another column, pick a stage under Move to in the list, or click a stage in the project's details. Add a note to say why, for example "PCBs arrived".
  • A new project shows in the first stage, marked "Stage not set yet", until someone gives it a stage: open it and click the stage it's at.
  • On hold: in a project's details, Put on hold and say why, for example "Waiting for PCBs". The card shows it until someone clicks Resume.
  • Updates: add a short update to a project at any time; the latest one shows on its card.
  • History: a project's details list every move, hold, resume and update with who and when. Each is also written to the Activity Logs.
  • Counts and search: click a count at the top (in progress, on hold, overdue, finished) to show only those projects; search finds projects by name, team, stage or note. Projects whose Project Manager status is Inactive or Completed are hidden unless you tick Show inactive and completed projects.
  • Who can do what: admins, managers and engineers can move projects, put them on hold and add updates; viewers can see the board. Only admins can Edit stages: rename, reorder, add or remove them. A stage with projects in it can't be removed, and the history keeps stage names as they were.
  • Everyone's board updates by itself within about 25 seconds of a change.
  • Project Manager's cards show each project's stage too, and their progress bar follows it (the first stage is 0%, the last 100%). Click the stage to open the board.
  • Deleting a project in Project Manager deletes its progress and history too.
