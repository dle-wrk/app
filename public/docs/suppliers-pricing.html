Adding a New Supplier

Register a Supplier

  1. Click Add Supplier button
  2. Enter supplier information:
    • Supplier Name
    • Website URL
    • Contact Email
    • Notes (optional but recommended)
    • Lead Time (in days)
    • Response Time (in hours)
  3. Click Save

  • Order History: View past purchase orders and completion rates

Accessing Pricing Tools

Live Price Lookup

Compare Supplier Prices in Real-Time

  1. Click the Live Price Lookup tab (Search icon)
  2. Enter one of: an internal SKU, a manufacturer part number, a DigiKey stock code (…-ND), or an LCSC stock code (C + digits)
  3. The system detects what you typed and queries the right suppliers:
    • DigiKey (OAuth2 client_credentials or refresh token)
    • Mouser Electronics
    • LCSC (live lookup + cached import)
    • Nexar / Octopart — aggregator covering Arrow, Heilind, Avnet and dozens more
    • Element14 / Farnell / Newark (Avnet)
    • TME (Transfer Multisort Elektronik)
  4. Look for the notice above the result cards — it tells you when the search term was translated (SKU→MFN or DigiKey stock code → real MPN) or when a supplier was skipped because it wouldn't recognise the code (LCSC codes).
  5. View API usage meters to track credit consumption per provider
  6. Click "View listing" to visit the supplier webpage
💡 Tip: The system caches pricing data for 30 days per (provider, part, quantity) to keep API costs down. Non-USD quotes (GBP, EUR, PLN, CAD, AUD, SGD) are converted using daily exchange rates cached alongside them.
✅ Fuzzy-match trap avoided: Sending an LCSC stock code like C105882 to Mouser or Element14 used to return unrelated $200+ parts. Live Price Lookup now recognises those codes and only asks LCSC. If you need cross-supplier quotes for the same part, search by the real manufacturer part number instead.

How live lookup matches parts

Smart part matching

The Pricing Directory now recognises what kind of code you typed and routes the query intelligently instead of blindly asking every supplier.

  • Internal SKU → MFN: if you type one of your own stock codes, the system looks up its stored manufacturer part number and searches suppliers by that instead.
  • DigiKey stock codes (anything ending in -ND): DigiKey is asked first to resolve the code to the real manufacturer part number, and every other supplier is then queried for that real MPN. Comparable quotes, no double DigiKey call.
  • LCSC stock codes (C followed by digits, e.g. C105882): only LCSC is queried. Other distributors would fuzzy-match to unrelated parts (a 100 nF capacitor was once priced at $241 via Pasternack this way).
  • Full supplier fan-out now covers DigiKey, Mouser, LCSC, Nexar (Octopart aggregator: Arrow, Heilind, Avnet, …), Element14/Farnell/Newark and TME.
  • Multi-currency: non-USD quotes (GBP, EUR, PLN, CAD, AUD, SGD) are converted to ZAR/USD automatically. Exchange rates refresh daily via a single call and are cached for 30 days.

Distributor stock code detection

Roughly 25% of items in the catalogue carry a distributor stock code in the manufacturer part number field. Live Price Lookup now handles those gracefully as described above; over time, cleaning those fields to the real MPN will give you the best cross-supplier price coverage.
