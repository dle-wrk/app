Automation & Workflow Management

Accessing Automation

Step 1: Navigate to Automation

  1. Click AUTOMATION → Automation Dashboard
  2. View real-time statistics:
    • Active Rules count
    • Scheduled Jobs
    • Pending Notifications
    • Auto-POs Created

Creating Automation Rules

Set Up an Automation Rule

  1. Click Automation Dashboard tab
  2. Click Create Rule button
  3. Define rule:
    • Rule name and description
    • Trigger type (Manual, Scheduled, Event-Based)
    • Conditions (e.g., stock level < 50)
    • Actions to perform (Create PO, Send Email, etc.)
  4. Set execution order if multiple actions
  5. Enable the rule

Auto-PO Configuration

Automatically Create Purchase Orders

  1. Click Auto-PO Config in sidebar
  2. For each component, configure:
    • Minimum stock level threshold
    • Automatic PO quantity (how many to order)
    • Preferred supplier
    • Auto-approval option
  3. Toggle component on/off for auto-PO
  4. System will create POs automatically when stock drops below minimum

Scheduled Jobs

Set Up Recurring Tasks

  1. Navigate to Automation Dashboard
  2. Click Scheduled Jobs tab
  3. Create new job:
    • Job name and description
    • Cron schedule (e.g., daily at 2 AM)
    • Action to perform
  4. Enable and monitor execution

Event Logging

Monitor Automation Events

  1. Click Event Log tab in Automation Dashboard
  2. View all automation activity:
    • Triggered rules
    • Completed actions
    • Failed operations
    • Performance metrics
  3. Export logs for analysis
✅ Best Practice: Start with simple automation rules and gradually add complexity as you become comfortable with the system.

Quality & Compliance Management

Accessing Quality Module

Step 1: Navigate to Quality Management

  1. Click QUALITY & ANALYTICS → Quality & Compliance
  2. View quality metrics dashboard with:
    • Passed inspections count
    • Failed inspections count
    • Open NCRs (Non-Conformance Reports)
    • Defect rate percentage

Quality Assurance Inspections

Schedule and Conduct QA Inspections

  1. Click QA Inspections tab
  2. Click Schedule Inspection
  3. Define inspection:
    • Component/product to inspect
    • Inspection type (incoming, in-process, final)
    • Sample size
    • Criteria and standards
  4. Record results:
    • Accept/reject decision
    • Defects found (if any)
    • Inspector notes
  5. System tracks pass/fail rates

Defect Tracking

Log and Manage Defects

  1. Click Defects tab
  2. Click Report Defect
  3. Enter defect details:
    • Component/product affected
    • Defect description
    • Severity (CRITICAL, MAJOR, MINOR)
    • Root cause (if known)
    • Assigned to (person responsible for fix)
  4. Track defect through resolution
  5. Close defect with closure notes

Non-Conformance Reports (NCR)

Create and Manage NCRs

  1. Click NCRs tab
  2. Click Create NCR
  3. Document non-conformance:
    • NCR number (auto-generated)
    • Issue description
    • Item/process affected
    • Date discovered
    • Immediate action taken
  4. Assign corrective actions
  5. Set follow-up review date
  6. Close NCR after verification
💡 Tip: Use the Quality module to maintain compliance records for ISO 9001, AS9100, or other standards your organization follows.
