1. Getting Started with Tracklab IM

First Time Login

Step 1: Access the Application

  1. Open your web browser and navigate to your Tracklab IM instance URL
  2. You should see the main dashboard after authentication
  3. Your profile information appears in the bottom-left of the sidebar
💡 Tip: Bookmark the URL for quick access. The application works best on desktop browsers (Chrome, Firefox, Safari, Edge).

Understanding the Interface

The Sidebar Navigation

The left sidebar contains all major sections, organized into groups:

  • Core Sections: Dashboard, Items & Inventory, Stock Tables, Reports & Ledger, Pricing Directory, Suppliers, Bookkeeping, Production Costs
  • CAD & Manufacturing: P&P Kit Booking, Bill of Materials, Pick & Place, Component Alternates
  • Project Management: Project Manager
  • Automation: Automation Dashboard, Auto-PO Config
  • Quality & Analytics: Quality & Compliance, Advanced Automation
  • Administration: System Config
💡 Tip: Click section headers in the sidebar to expand/collapse categories and reduce clutter.

Essential Settings

Step 1: Configure Basic Settings

  1. Click Settings → System Config
  2. Set your preferred visual theme (Dark/Light mode)
  3. Enable/disable low stock alerts
  4. Configure sync frequency for real-time or interval-based updates

2. Dashboard Overview

The Dashboard is your command center, providing real-time insights into your inventory, projects, and business operations.

Key Metrics Cards

Understanding the Statistics

  • Total Items: Complete inventory count with trend percentage
  • Active Projects: Current project status (Stable/At Risk)
  • Low Stock Alerts: Items requiring immediate attention
  • Critical Shortages: Number of items urgently needed
  • Asset Valuation: Total monetary value of inventory

Inventory Insights

Items by Category

View inventory distribution across all categories:

  1. Scroll to "Items by Category" section
  2. Hover over charts to see category names and SKU counts
  3. Click category to drill down into that inventory subset

Stock Status Overview

Monitor Stock Levels

  • Status: OK (67%): Items with adequate stock levels
  • Status: Low (8%): Items below low stock threshold
  • Status: Critical (25%): Items requiring urgent reordering
✅ Pro Tip: Check the dashboard every morning to identify critical items that need reordering.

3. Inventory Management

Accessing Inventory

Step 1: Navigate to Items & Inventory

  1. Click Items & Inventory in the sidebar
  2. You'll see a comprehensive table of all inventory items
  3. Use search (⌘K or Ctrl+K) to quickly find items by SKU, name, or ID

Search and Filter

Finding Specific Items

  1. Click the search box at the top: "Search SKU, name, ID..."
  2. Type part number, SKU, or item name
  3. Use dropdown filters:
    • Stock Code filter for exact SKU matches
    • Status filter (Active/Inactive/etc.)
    • Stock Health filter (All Levels, Low, Critical)
  4. Results update in real-time
💡 Keyboard Shortcut: Press ⌘K (Mac) or Ctrl+K (Windows) from anywhere to open the global search.

Adding New Items

Step 1: Create a New Item

  1. Click the Add Item button
  2. Fill in required fields:
    • Part Number (unique identifier)
    • Item Name
    • Description
    • Category (Component, Consumable, Product, etc.)
    • Stock Level
    • Unit Price
    • Low Stock Level (threshold for alerts)
  3. Click Save

Updating Stock Levels

Book In Components

  1. Click Book In Component button on dashboard
  2. Select the item to increase stock
  3. Enter quantity received
  4. Add reference/PO number
  5. Confirm transaction

Book Out Components

  1. Select item in inventory table
  2. Click Book Out option
  3. Enter quantity used/removed
  4. Add project or work order reference
  5. Confirm transaction

Item Details & Editing

View Full Item Information

  1. Click an item row to expand details
  2. View all properties: manufacturer part numbers, supplier numbers, datasheets, weblinks
  3. Edit inline by clicking field values
  4. Changes save automatically
⚠️ Warning: Carefully verify part numbers before creating new items to avoid duplicates. Check Similar Part Numbers section before adding.

4. Supplier Management

Accessing Suppliers

Step 1: Navigate to Suppliers

  1. Click Suppliers in the sidebar
  2. View list of all registered suppliers
  3. Search by supplier name or ID

Adding a New Supplier

Register a Supplier

  1. Click Add Supplier button
  2. Enter supplier information:
    • Supplier Name
    • Website URL
    • Contact Email
    • Notes (optional but recommended)
    • Lead Time (in days)
    • Response Time (in hours)
  3. Click Save

Supplier Performance Tracking

Monitor Supplier Metrics

  • Lead Time: Average days from order to delivery
  • Response Time: Average hours to respond to inquiries
  • Quality Score: Tracked through defects and returns
  • Order History: View past purchase orders and completion rates
💡 Tip: Maintain multiple suppliers for critical components to avoid supply chain disruptions.

5. Pricing Directory

Accessing Pricing Tools

Step 1: Open Pricing Directory

  1. Click Pricing Directory in the sidebar
  2. You'll see three tabs: Live Price Lookup, Bulk Pricing, Price Directory

Live Price Lookup

Compare Supplier Prices in Real-Time

  1. Click the Live Price Lookup tab (Search icon)
  2. Enter part number or manufacturer part number
  3. System queries multiple suppliers:
    • DigiKey
    • Mouser Electronics
    • LCSC (web-scraped pricing)
  4. View API usage meters to track credit consumption
  5. Click "View listing" to visit supplier webpage
💡 Tip: The system caches pricing data for 30 days to reduce API costs while keeping prices current.

Bulk Pricing Wizard

Update Prices for Multiple Items

  1. Click the Bulk Pricing tab (Settings icon)
  2. Enter calibration parameters:
    • Wholesale volume breakpoints
    • Percentage markups for different volumes
  3. Select items to update
  4. Review calculated prices
  5. Click Apply to update database

Price Directory Browser

Browse All Inventory Prices

  1. Click the Price Directory tab (Database icon)
  2. Browse paginated inventory (50 items per page)
  3. Filter by category using buttons (All Classes, Microcontrollers, Capacitors)
  4. Navigate pages using chevron buttons
  5. View total item count
✅ Best Practice: Review pricing quarterly and update based on market conditions and supplier agreements.

6. Manufacturing & Production

Bill of Materials (BOM)

Create and Manage BOMs

  1. Navigate to CAD & MANUFACTURING → Bill of Materials
  2. Click Create New BOM
  3. Enter assembly name and description
  4. Add components by:
    • Searching existing inventory
    • Specifying quantity needed per unit
    • Adding designator (reference number)
    • Including footprint and package info
  5. Review total component cost
  6. Save BOM for production use

Production Kits

Manage Production Kits

  1. Navigate to CAD & MANUFACTURING → P&P Kit Booking
  2. View available kits with status:
    • READY: Available for use
    • STAGING: Being prepared
    • BLOCKED: Temporarily unavailable
    • ACTIVE: Currently in use
  3. Book a kit for a production run
  4. Track kit status and update as production progresses

Pick & Place Operations

Manage Pick & Place Components

  1. Navigate to CAD & MANUFACTURING → Pick & Place
  2. View all P&P components organized by project
  3. Track component designators and quantities
  4. Update placement status as manufacturing progresses

Production Costs

Calculate and Track Production Costs

  1. Navigate to Production Costs
  2. View products with:
    • Model numbers
    • Production cost (BOM cost + labor)
    • Selling price
    • Margin calculation
  3. Edit costs and prices as needed
💡 Tip: Track BOM costs carefully - they're the foundation of accurate pricing and margin calculations.

7. Bookkeeping & Accounting

Accessing the Bookkeeping Module

Step 1: Navigate to Bookkeeping

  1. Click Bookkeeping in the sidebar
  2. You'll see tabbed interface with sections:
    • Overview
    • Chart of Accounts
    • Customers - Manage customer information
    • Vendors - Manage supplier information
    • Invoices - Customer invoices with smart autocomplete
    • Bills - Supplier bills
    • Purchase Orders - Supplier or Customer orders (with mode switching)
    • Payments Received - Customer payments
    • Payments Made - Supplier payments
    • Expenses
    • Reports

Creating Invoices

Invoice Creation Process (Enhanced UI)

  1. Click Invoices tab
  2. Click Create Invoice
  3. Fill invoice details:
    • Select customer
    • Set invoice date and due date
    • Choose currency (ZAR, USD, EUR, GBP)
    • Enable Warranty Claim if this is a warranty replacement (voids all pricing)
  4. Add line items using Smart Autocomplete:
    • Type SKU/Part # in autocomplete field
    • System searches inventory and production products in real-time
    • Click to select - automatically fills description and unit price
    • Quantity and tax rate populated per item
    • Line total updates automatically
  5. Modern Card-Based UI:
    • Each line item displayed as spacious card
    • Clear visual hierarchy with line number and remove button
    • Subtotal + Tax summary automatically calculated
    • If warranty claim enabled, shows "Warranty claim - pricing voided"
  6. Review subtotal, taxes, and total
  7. Click Finalize & Print (changed from "Finalize & Send")
  8. Generates print-ready PDF for delivery or email

Invoice Features

Smart Item Autocomplete

  • Search Inventory & Production Items: Type part number to search both regular and production stock
  • Auto-populate Details: Selecting item fills description, unit price, and stock level
  • Dynamic Filtering: Results update as you type
  • Production Products: Invoices can include manufacturing items with selling prices

Warranty Claims

  • Enable toggle on invoice to mark as warranty claim
  • Effect: All line item pricing shows R0.00
  • Display: Shows "Warranty claim - pricing voided" indicator
  • Use Case: For warranty replacement orders with no charge

Managing Bills (Purchase Invoices)

Record Supplier Bills

  1. Click Bills tab
  2. Click Create Bill
  3. Select supplier
  4. Enter bill number and date
  5. Add line items with amounts and accounts
  6. Save and track for payment processing

Purchase Orders (New: Supplier/Customer Modes)

Create Purchase Orders with Mode Selection

  1. Click Purchase Orders tab
  2. Click Create PO
  3. Select Order Type (NEW!):
    • Supplier Mode: For ordering regular inventory/components
      • Shows inventory items (non-production stock)
      • Select from suppliers list (Mouser, Digikey, LCSC, etc.)
      • Use for component sourcing and inventory replenishment
    • Customer Mode: For customer production orders
      • Shows production stock items only
      • Select from customers list (Bokpoort, Damlaagte, DEWA, Sasol, etc.)
      • Use for custom manufacturing and special orders
  4. Dropdown automatically updates: Shows suppliers or customers based on selected mode
  5. Set order date and expected delivery date
  6. Add line items using smart autocomplete:
    • Items filtered based on selected mode (inventory vs production)
    • Auto-populate unit price and description
    • Select tax rate
  7. System calculates subtotal, tax, and total automatically
  8. Click Save Draft to save without sending
  9. Click Save & Send to submit to supplier/customer

Purchase Order Modes Explained

Supplier Mode vs Customer Mode

Feature Supplier Mode Customer Mode
Partner Type External Suppliers Customers/Clients
Item Filter Regular Inventory Items Production Stock Items
Use Case Component Ordering Custom Manufacturing
Status Flow DRAFT → SENT → RECEIVED DRAFT → SENT → RECEIVED
Convert to Bill Yes (from supplier) Yes (bill to customer)

Recording Payments

Payments Received from Customers

  1. Click Payments Received tab
  2. Click Record Payment
  3. Select customer from the customer list (Bokpoort, Damlaagte, DEWA, Sasol, etc.)
  4. Select invoice(s) to allocate payment against
  5. Enter payment method (EFT, Check, Cash, etc.) and amount
  6. Allocate payment to invoices
  7. System updates customer balance and invoice status automatically

Payments Made to Suppliers

  1. Click Payments Made tab
  2. Click Record Payment
  3. Select supplier and bills
  4. Enter payment details (method, amount, date)
  5. Confirm and record in accounting ledger

Financial Reports

Generate Reports

  1. Click Reports tab
  2. Available reports:
    • Balance Sheet
    • Income Statement
    • Cash Flow Statement
    • Accounts Receivable Aging
    • Accounts Payable Aging
  3. Select date range
  4. Export to PDF or Excel
⚠️ Important: Reconcile accounts monthly and maintain accurate records for audit purposes.

8. Automation & Workflow Management

Accessing Automation

Step 1: Navigate to Automation

  1. Click AUTOMATION → Automation Dashboard
  2. View real-time statistics:
    • Active Rules count
    • Scheduled Jobs
    • Pending Notifications
    • Auto-POs Created

Creating Automation Rules

Set Up an Automation Rule

  1. Click Automation Dashboard tab
  2. Click Create Rule button
  3. Define rule:
    • Rule name and description
    • Trigger type (Manual, Scheduled, Event-Based)
    • Conditions (e.g., stock level < 50)
    • Actions to perform (Create PO, Send Email, etc.)
  4. Set execution order if multiple actions
  5. Enable the rule

Auto-PO Configuration

Automatically Create Purchase Orders

  1. Click Auto-PO Config in sidebar
  2. For each component, configure:
    • Minimum stock level threshold
    • Automatic PO quantity (how many to order)
    • Preferred supplier
    • Auto-approval option
  3. Toggle component on/off for auto-PO
  4. System will create POs automatically when stock drops below minimum

Scheduled Jobs

Set Up Recurring Tasks

  1. Navigate to Automation Dashboard
  2. Click Scheduled Jobs tab
  3. Create new job:
    • Job name and description
    • Cron schedule (e.g., daily at 2 AM)
    • Action to perform
  4. Enable and monitor execution

Event Logging

Monitor Automation Events

  1. Click Event Log tab in Automation Dashboard
  2. View all automation activity:
    • Triggered rules
    • Completed actions
    • Failed operations
    • Performance metrics
  3. Export logs for analysis
✅ Best Practice: Start with simple automation rules and gradually add complexity as you become comfortable with the system.

9. Quality & Compliance Management

Accessing Quality Module

Step 1: Navigate to Quality Management

  1. Click QUALITY & ANALYTICS → Quality & Compliance
  2. View quality metrics dashboard with:
    • Passed inspections count
    • Failed inspections count
    • Open NCRs (Non-Conformance Reports)
    • Defect rate percentage

Quality Assurance Inspections

Schedule and Conduct QA Inspections

  1. Click QA Inspections tab
  2. Click Schedule Inspection
  3. Define inspection:
    • Component/product to inspect
    • Inspection type (incoming, in-process, final)
    • Sample size
    • Criteria and standards
  4. Record results:
    • Accept/reject decision
    • Defects found (if any)
    • Inspector notes
  5. System tracks pass/fail rates

Defect Tracking

Log and Manage Defects

  1. Click Defects tab
  2. Click Report Defect
  3. Enter defect details:
    • Component/product affected
    • Defect description
    • Severity (CRITICAL, MAJOR, MINOR)
    • Root cause (if known)
    • Assigned to (person responsible for fix)
  4. Track defect through resolution
  5. Close defect with closure notes

Non-Conformance Reports (NCR)

Create and Manage NCRs

  1. Click NCRs tab
  2. Click Create NCR
  3. Document non-conformance:
    • NCR number (auto-generated)
    • Issue description
    • Item/process affected
    • Date discovered
    • Immediate action taken
  4. Assign corrective actions
  5. Set follow-up review date
  6. Close NCR after verification
💡 Tip: Use the Quality module to maintain compliance records for ISO 9001, AS9100, or other standards your organization follows.

11. Pro Tips & Best Practices

Daily Operations Checklist

Morning Routine

  • Check Dashboard for critical shortages
  • Review low stock alerts
  • Process any pending purchase orders
  • Check automation event logs for errors
  • Review pending notifications

Weekly Tasks

Weekly Maintenance

  • Update inventory counts for high-value items
  • Review supplier performance metrics
  • Process incoming inventory
  • Check quality metrics and defect trends
  • Reconcile accounts receivable/payable

Monthly Reviews

Month-End Procedures

  • Complete physical inventory count
  • Reconcile with system records
  • Review and approve all transactions
  • Generate financial reports
  • Update supplier performance scores
  • Review pricing and adjust as needed

System Optimization Tips

Performance Improvements

  • Bulk Operations: Use bulk pricing wizard instead of updating items one-by-one
  • Keyboard Shortcuts: Use Ctrl+K/⌘K for global search instead of clicking
  • Filters: Apply filters before searching to reduce result set
  • Automation: Set up rules to eliminate manual, repetitive tasks
  • Caching: Pricing data cached 30 days to reduce API costs

Data Management Best Practices

Critical Guidelines

  • Unique Part Numbers: Never duplicate SKUs - verify before creating items
  • Supplier Master: Maintain accurate supplier information for correspondence
  • Regular Backups: Ensure database backups occur regularly
  • Access Control: Limit admin access to authorized personnel only
  • Audit Trail: Monitor who makes what changes for compliance

Troubleshooting Common Issues

Slow Performance

  • Clear browser cache (Ctrl+Shift+Delete)
  • Use filters to reduce large result sets
  • Check internet connection speed
  • Try different browser if issue persists

Missing or Incorrect Data

  • Refresh page (F5 or ⌘R)
  • Clear filters to ensure complete view
  • Check for pending sync operations
  • Verify user permissions for field visibility

API Connection Issues

  • Check API key configuration in system settings
  • Verify supplier API credentials are valid
  • Check network firewall rules
  • Review API rate limits and throttling

Advanced Techniques

Power User Features

  • Custom Fields: Add custom attributes to items for your business needs
  • Bulk Import: Import items via CSV for faster onboarding
  • Export Templates: Create reusable export templates for reports
  • API Integration: Connect external systems via REST API for seamless data flow
  • Workflow Automation: Chain multiple rules for complex business processes
